# Play&Code — игровое обучение HTML, CSS и JavaScript

**Live-сайт:** https://demonzhanowsky.github.io/vanila/

Учебный проект: тематический сайт из 10 страниц с обзором сервисов для изучения веб-разработки в игровой форме.

## Технологии
HTML5, CSS3 (БЭМ), Vanilla Framework 4 (CDN), JavaScript.

## Запуск
Откройте `index.html` в браузере или запустите `python3 -m http.server`.

## Структура
`*.html` — страницы, `css/custom.css` — свои стили, `js/main.js` — скрипты.
