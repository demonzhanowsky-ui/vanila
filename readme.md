# Play&Code — учите вёрстку и код через игру

🔗 **Live-сайт:** https://demonzhanowsky-ui.github.io/vanila/index.html

Учебный проект: тематический сайт об игровом обучении HTML, CSS и JavaScript.
Обзор сервисов (Flexbox Froggy, Grid Garden, CodeCombat, CodeHavr), три уровня
обучения, сравнение сервисов, маршрут освоения и FAQ.

---

## 🛠 Технологии

- **HTML5** — семантическая и валидная разметка
- **CSS3** — кастомные стили поверх фреймворка
- **Vanilla Framework** — CSS-фреймворк ([vanillaframework.io](https://vanillaframework.io))
- **JavaScript** — интерактив (бургер-меню, навигация)

## 📄 Страницы (10 шт.)

1. `index.html` — Главная
2. `html.html` — HTML
3. `css.html` — CSS
4. `javascript.html` — JavaScript
5. `compare.html` — Сравнение
6. `video.html` — Видео
7. `route.html` — Маршрут
8. `history.html` — Викторина
9. `faq.html` — FAQ
10. `contacts.html` — Контакты

## ✨ Возможности

- Адаптивная вёрстка (Mobile-First) — 3 контрольные точки: `<768px`, `≥768px`, `≥992px`
- Responsive-навигация с бургер-меню
- Сайдбар с разделами и формой подписки
- Семантическая таблица, iframe-видео, responsive-изображения (`srcset`, `sizes`)
- Семантическая разметка: `header`, `main`, `aside`, `footer`, `nav`
